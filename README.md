# Quran Web - القرآن الكريم

A comprehensive Islamic digital platform featuring Quran recitations, prayer times, Islamic radio stations, and Quranic tafsir. Built with modern web technologies for the Muslim community.

## 🌟 Features

### 📖 Quran Recitations
- Listen to beautiful Quran recitations from renowned reciters
- Search and filter reciters by name
- Multiple audio formats available
- High-quality streaming from mp3quran.net

### 🕌 Prayer Times
- Accurate prayer times for multiple cities
- Support for major Islamic cities worldwide
- Both Gregorian and Hijri date display
- Beautiful prayer time cards with visual indicators

### 📻 Islamic Radio
- Live Islamic radio stations from around the world
- Arabic language content
- Real-time streaming
- Search functionality for stations

### 📚 Quran Tafsir
- Detailed interpretations of Quranic verses
- Arabic tafsir content
- Search by surah name
- Scholarly interpretations and explanations

### 🎨 Modern Design
- Responsive design for all devices
- Beautiful gradient backgrounds
- Smooth animations and transitions
- Professional Material-UI components
- Arabic typography support

## 🛠️ Technology Stack

- **Frontend Framework**: Next.js 14
- **UI Library**: React 18
- **Styling**: Material-UI (MUI) 5
- **Animations**: Framer Motion
- **Icons**: Material-UI Icons
- **HTTP Client**: Axios
- **Fonts**: Google Fonts (Inter, Noto Sans Arabic)
- **Deployment**: Vercel

## 📦 Installation

### Prerequisites
- Node.js 18.0.0 or higher
- npm 8.0.0 or higher

### Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/quran-web-app.git
   cd quran-web-app
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000)

## 🌐 API Integration

The application integrates with several Islamic APIs:

- **mp3quran.net API** - For Quran recitations and radio stations
- **Aladhan API** - For prayer times calculation
- **Islamic Network APIs** - For tafsir content
